Gemini 與瀏覽器設定

Gemini Live API 金鑰

輸入 Google AI Studio 的 Gemini API 金鑰。金鑰會保存在這台電視的 App 儲存區，手機不必連線。

這是直接連 Gemini 的個人電視設定。Google 提醒用戶端金鑰可能被取出；請勿把含有個人金鑰的 App 分享或公開。

所有網站都會交給 LG 瀏覽器開啟。

  1. 需要調整瀏覽器行為時，請進入 LG 瀏覽器的「設定」。
  2. 需要時打開「彈出視窗阻擋／Pop-up Blocker」。
  3. 此選項只控制瀏覽器是否阻擋彈出視窗。

LG 2018 webOS 世代的瀏覽器手冊列出彈出視窗阻擋，沒有列出一般網頁廣告阻擋。因此頁面內廣告、YouTube 或串流影片廣告仍可能出現。
